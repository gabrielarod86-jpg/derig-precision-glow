# Dérig Precision Hub

Crie um site institucional e comercial moderno para a empresa **Dérig Implantes do Brasil**, inspirado no layout premium previamente demonstrado, com visual de alta tecnologia, estética internacional e foco principal nos produtos.

O objetivo do site é reposicionar a Dérig como uma marca de implantes odontológicos premium, com aparência de empresa grande, tecnológica, confiável e com produtos de qualidade A+.

O site deve seguir os parâmetros do manual de identidade visual da marca:

* Usar a cor principal laranja Dérig: `#F37A21`
* Usar preto institucional: `#23201F`
* Usar fundo escuro premium: `#070707` ou `#11100F`
* Usar branco e cinza claro como contraste
* Respeitar o logotipo Dérig sem distorcer, alterar proporções ou modificar cores
* Usar tipografia com aparência próxima de **Encode Sans** ou **Sansation**
* Manter visual limpo, sofisticado, técnico e premium

O site deve ser desenvolvido em **React + Tailwind CSS**, responsivo e mobile-first.
